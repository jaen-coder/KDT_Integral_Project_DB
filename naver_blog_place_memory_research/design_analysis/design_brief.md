## 후보 D1: 순간을 붙잡는 사진 카드 (우선 검토)

**한 문장**  
현장에서 남긴 사진 조각(네컷·필름·한 컷)을 짧은 메모와 함께 장소에 붙이는 표현.

**연결 UX**  
사진과 메모 작성, 현장에서 타인의 기록 열람, 내 기록을 다시 찾아보기

**데이터에서 확인(A/B)**  
네컷·포토부스·스티커사진, 필름·그레인·오래된 질감, 사진 결과물 시각 평가, 보정·필터(시각)  
관련 게시물 수(참고): 83

**디자이너 해석 제안(C)**  
- 네컷/스트립형 카드 레이아웃(제안)
- 필름 감 필터는 선택 옵션으로만(제안)
- 날짜·짧은 메모 슬롯(제안)

**색상 방향**  
자료에서 앱 색상 HEX는 확인되지 않음. 사진이 주인공이 되도록 중립·저채도 프레임을 디자이너 제안값으로 검토.

**이미지·질감**  
네컷·스티커사진·하루필름 등 '물리 사진 매체' 경험이 직접 언급됨(다수는 행위 언급, 소수만 명시적 긍정). 픽셀/Y2K로 단정하지 않음.

**타이포**  
손글씨·폰트 직접 근거는 매우 적음 → 가독성 우선 본문, 손글씨 장식은 선택.

**아이콘·장식·캐릭터**  
스티커는 제품/다꾸 맥락의 직접 근거와 분리해, 기록 카드의 가벼운 장식 옵션으로만 해석 제안.

**사진·메모 카드**  
사진 1~4장 + 한두 줄 메모. 콜라주 강제는 근거 부족.

**문체·카피 예시**  
- “여기 빛 좋았음”
- “오늘 여기 지나침”
- “이 골목 다시 오고 싶음”

**주의 (가독성·작성 부담·현장)**  
보정·필터 강제는 사용 부담. 꾸미기 귀찮음(부정/혼합)과 충돌 가능.

**반대 근거·미확인**  
꾸미기 부담·귀찮음 직접 언급 존재; UI 색상 선호는 미확인.

**검증 질문**  
- 장소 기록 시 네컷/스트립형 카드가 일반 정사각 카드보다 남기고 싶은가?
- 필터는 기본 적용과 선택 적용 중 무엇을 선호하는가?

## 후보 D2: 장소의 빛과 색을 발견하는 지도 (우선 검토)

**한 문장**  
따뜻한 조명·색채·깔끔한 공간이 좋다는 장소 경험을, 발견 순간의 시각 단서로 절제해 반영.

**연결 UX**  
지도에서 기록 발견, 현장에서 타인의 기록 열람

**데이터에서 확인(A/B)**  
조명·빛과 분위기, 인테리어·공간 디자인 선호, 공간·사물의 색채 분위기, 깔끔·심플·정돈, 구체 색 이름+평가  
관련 게시물 수(참고): 79

**디자이너 해석 제안(C)**  
- 지도 핀/카드에 과도한 테마색 대신 사진 썸네일 강조(제안)
- 따뜻한 중성 배경 톤은 디자이너 제안값(공간 조명 선호를 UI 색으로 비약하지 않음)
- 정보 밀도 낮은 카드(깔끔·한눈에 보기 좋음 근거와 연결)

**색상 방향**  
원문에 특정 HEX 없음. 공간의 '따뜻함/무채색/알록달록'은 장소·제품 평가이므로 앱 크로마로 직접 이식 금지. 디자이너 제안: 저채도 웜 그레이 배경 + 사진 본연 색.

**이미지·질감**  
한지·자연광·조명 등 공간 질감은 배경 장식이 아니라 사용자 사진으로 전달.

**타이포**  
짧은 장소 메모가 읽히도록 본문 가독성 우선.

**아이콘·장식·캐릭터**  
장식보다 장소 사진·짧은 단서가 주인공.

**사진·메모 카드**  
지도 → 카드: 사진 크게, 텍스트 1~2줄, 여백 확보.

**문체·카피 예시**  
- “조명 따뜻한 자리”
- “벽 색이 조용함”
- “여긴 사진 잘 나옴”

**주의 (가독성·작성 부담·현장)**  
공간 미감을 앱 스킨 전체의 레트로/파스텔로 확장하지 말 것.

**반대 근거·미확인**  
시대 스타일(Y2K 등) 직접 근거는 소수이며 패션·카페 맥락. UI 스타일 선호로 미검증.

**검증 질문**  
- 지도에서 기록을 고를 때 색 테마보다 사진 썸네일이 더 중요한가?
- 따뜻한 분위기 표현이 과하면 가독성을 해치는가?

## 후보 D3: 가볍게 남기고, 꾸밈은 선택 (탐색 후보)

**한 문장**  
짧은 메모·사진 모음은 쉽게, 스티커·손꾸밈은 원하지 않으면 건너뛸 수 있게.

**연결 UX**  
사진과 메모 작성, 내 기록을 다시 찾아보기

**데이터에서 확인(A/B)**  
스티커·프레임·꾸밈, 꾸미기 부담·귀찮음, 짧은 글·가독성, 손글씨·글씨체·폰트, 포토덤프·사진 모아보기  
관련 게시물 수(참고): 58

**디자이너 해석 제안(C)**  
- 기본 작성 플로는 사진+한 줄(제안)
- 스티커/프레임은 옵션 서랍(제안)
- 필수 다꾸형 UI 지양

**색상 방향**  
작성 화면은 높은 대비·단순한 면 구성(디자이너 제안값). 파스텔 강제 근거 없음.

**이미지·질감**  
포토덤프형 모아보기는 간접 근거(형식 언급). 강요하지 않음.

**타이포**  
짧은 글 선호·가독성 댓글 단서와 연결 가능하나 표본 소수의 직접 근거.

**아이콘·장식·캐릭터**  
스티커 긍정도 있으나 꾸미기 귀찮음 반대 근거 → 기본 OFF.

**사진·메모 카드**  
작성 최소 단계: 사진 선택 → 한 줄 → 게시. 꾸미기는 이후.

**문체·카피 예시**  
- “한 줄만 남겨도 충분해요”
- “꾸미기는 나중에”
- “사진만 올려도 OK”

**주의 (가독성·작성 부담·현장)**  
장식 밀도가 현장 작성 속도를 해치면 핵심 과업 우선.

**반대 근거·미확인**  
꾸미기 부담 언급 posts=1
