- `naver_trend_clean_20261120_192943.csv`: 분석에 바로 사용할 최종 데이터

팀 분석에서는 CSV를 사용하면 됩니다. Notebook은 데이터가 어떤 기준과 과정을 거쳐 만들어졌는지 확인하기 위한 작업 기록입니다.

## 수집 목적

위치 기반 기록 플랫폼의 2030 타깃 적합성을 검토하기 위해 네이버 검색어 트렌드 API로 관련 키워드의 월별 검색 추이를 수집했습니다.

- 조회 기간: 2025-01-01 ~ 2026-10-31
- 조회 단위: 월별
- 키워드: 11개
- 성별: 전체, 남성, 여성
- 연령: 전체 및 11개 연령 구간
- 전체 API 요청 조건: 396개

## 수집 키워드

- 일상 기록: 일상기록, 사진일기, 포토덤프
- 기록 보관: 사진정리, 디지털다이어리, 여행기록
- 장소 탐색: 동네산책, 동네탐방, 스탬프투어
- 타인의 흔적: 전시방명록, 카페방명록

## Notebook 작업 흐름

1. Python 가상환경과 필수 패키지 상태를 확인했습니다.
2. `.env`에 저장된 API 인증정보로 연결 테스트를 진행했습니다.
3. 키워드·성별·연령 조합 396개를 생성했습니다.
4. 재시도와 오류 구분 기능이 포함된 API 요청 함수를 작성했습니다.
5. 전체 조건을 자동으로 수집했습니다.
6. API 응답을 원본 JSON으로 저장하고 무결성을 확인했습니다.
7. 응답 데이터를 행 단위로 변환하고 날짜·숫자 타입을 정제했습니다.
8. 중복, 결측, 날짜 범위, 코드·라벨 일치 여부 등을 검증했습니다.
9. 분석용 CSV를 저장한 뒤 다시 불러와 최종 검증했습니다.

## CSV 주요 항목

- `condition_id`: API 요청 조건 식별자
- `normalization_scope_id`: 검색 지수의 정규화 범위 식별자
- `category`: 키워드 분류
- `keyword`: 수집 키워드
- `gender_code`, `gender_label`: 성별 코드와 이름
- `age_code`, `age_label`: 연령 코드와 이름
- `period`: 검색 추이 기준 월
- `ratio`: 네이버 검색량 상대 지수
- `start_date`, `end_date`: 조회 기간
- `request_status`: API 응답 상태

`gender_code=all`은 전체 성별, `age_code=all`은 전체 연령을 의미합니다.

## 분석 시 주의사항

`ratio`는 실제 검색량이 아니라 각 API 요청 조건 안에서 가장 높은 값을 100으로 환산한 상대 지수입니다.

따라서 서로 다른 `normalization_scope_id`의 값을 실제 검색량처럼 직접 비교하면 안 됩니다. 특히 성별이나 연령대별 `ratio` 크기만으로 어느 집단의 검색량이 더 많다고 해석할 수 없습니다.

분석에서는 다음과 같은 방식이 적절합니다.

- 동일 조건 안에서 월별 상승·하락 추이 확인
- 검색 지수가 높아진 시점과 계절성 확인
- 키워드별 피크 시점 및 변화 패턴 비교
- 20대·30대 조건에서 나타나는 관심 시점과 지속성 탐색

API가 반환하지 않은 월은 검색량이 0이라는 의미가 아닙니다. 해당 월의 행을 생성하거나 `ratio=0`으로 대체하지 않았습니다.
